# 版本记录

## v1.0.0 — 2026-11-24

首个完整版本。

### 新增

- **站点**：单页结构，序 + 六章 + 页脚，共 7 个锚点章节。
- **图像**：16 张程序化生成 SVG
  - 首屏 1 张（界痕横贯天际）
  - 景物 3 张（昆仑 / 奥瑞恩巨城 / 界痕）
  - 场景 3 张（界门 / 战场 / 界碑）
  - 人物 6 张（玄洲 3 / 奥瑞恩 3）
  - 节点地图 3 张（三次界战）
- **音频**：150 秒无缝循环音景 `bgm-epoch.wav`，纯标准库合成，四层结构。
- **交互**：
  - Canvas 粒子场 + 界痕扰动（`field.js`）
  - 音景播放器，含淡入淡出与合成降级（`audio.js`）
  - 导航折叠、滚动揭示、逐字揭示、轻视差（`ui.js`）
- **样式**：`base.css`（设计 token 与组件）+ `site.css`（图片适配与响应式）。
- **文档**：README、世界观全稿、资产清单、部署指南、版本记录。

### 设计决策

- 丹砂 `#A63D2F` 全站仅用于「至今」，强化「未完成」语义。
- 圆角上限 2px，禁用 `box-shadow` 光晕，发光全部由 SVG 滤镜与 Canvas 混合实现。
- 音景默认静音，永不自动播放。
- 玄洲侧宋体竖排语感，奥瑞恩侧衬线大写几何——排版语言即立场。

### 已知限制

- WAV 体积 6.3 MB，移动端首次加载偏慢，建议转 MP3/Opus（见 `docs/DEPLOY.md`）。
- Safari 对 SVG `filter` 支持较弱，辉光效果会减弱但不影响可读性。
- 人物立绘为剪影风格，非写实插画。
